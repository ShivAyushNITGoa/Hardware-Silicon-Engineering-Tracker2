# Semiconductor Simulation Projects

## Overview

Hands-on projects for understanding semiconductor devices, circuits, and fabrication concepts using simulation tools.

## Project 1: MOSFET Characterization

Tools:
- LTspice
- Ngspice
- HSPICE

Study:
- I-V characteristics
- Threshold voltage
- Channel length modulation
- Temperature effects

## Project 2: CMOS Inverter Analysis

Tasks:
- DC sweep
- Voltage transfer curve
- Noise margin calculation
- Delay analysis

## Project 3: PN Junction Simulation

Study:
- Forward bias
- Reverse bias
- Breakdown behavior
- Depletion width

## Project 4: TCAD NMOS Simulation

Tools:
- Sentaurus TCAD
- Silvaco ATLAS

Learn:
- Doping profiles
- Device dimensions
- Carrier transport

## Project 5: Analog IC Simulation

Design:
- Current mirror
- Differential amplifier
- Common source amplifier

## Project 6: Process Simulation

Study:
- Oxidation
- Implantation
- Diffusion
- Etching

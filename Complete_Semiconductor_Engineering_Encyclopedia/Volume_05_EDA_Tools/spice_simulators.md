# SPICE Simulation Tools

## Overview
SPICE simulators analyze electronic circuits before fabrication.

## LTspice

Used for:
- Analog simulation
- MOSFET analysis
- Amplifier design
- Power circuits

## Ngspice

Open-source simulator supporting:
- Analog circuits
- CMOS circuits
- Device models

## Spectre

Cadence industry simulator used for:
- Analog IC verification
- RF simulation
- Transistor modelling

## HSPICE

Synopsys simulator used for:
- High accuracy transistor simulation
- Standard cell characterization
- Memory analysis

## Important Analyses

- DC sweep
- AC analysis
- Transient analysis
- Noise analysis
- Monte Carlo analysis

## Projects

- CMOS inverter
- MOSFET characterization

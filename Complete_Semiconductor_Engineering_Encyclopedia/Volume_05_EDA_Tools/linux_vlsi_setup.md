# Linux Environment Setup for VLSI

## Why Linux?

Most semiconductor EDA tools run on Linux environments.

## Recommended Setup

- Ubuntu Linux
- Virtual Machine
- Dual boot
- WSL2

## Essential Skills

- Terminal commands
- Shell scripting
- File permissions
- Environment variables
- Makefiles

## Required Packages

- GCC
- Python
- Git
- CMake
- Perl
- Tcl/Tk

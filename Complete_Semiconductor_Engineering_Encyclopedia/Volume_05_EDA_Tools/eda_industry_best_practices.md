# EDA Industry Best Practices

## Design Environment Management

- Version controlled design files
- Reproducible tool setup
- Documented constraints
- Automated scripts

## Flow Quality Checks

- Lint
- CDC analysis
- Timing checks
- Power analysis
- DRC/LVS verification

## Automation

Important skills:

- Tcl scripting
- Python automation
- Linux scripting
- Regression management

## Industry Principle

A good design flow must be accurate, repeatable and scalable.

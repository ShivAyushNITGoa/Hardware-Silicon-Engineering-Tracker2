# Complete Semiconductor Industry Project Checklist

## Project Planning

- Define requirements
- Select architecture
- Create specifications

## Design Phase

- Block diagram
- Interface definition
- RTL/circuit implementation

## Verification Phase

- Verification plan
- Testbench
- Assertions
- Coverage

## Implementation Phase

Digital:
- Synthesis
- Timing analysis
- Physical design

Analog:
- Simulation
- Layout
- DRC/LVS

## Documentation

Required:
- Design document
- Test report
- Results
- Lessons learned

## Industry Readiness

A complete project should demonstrate:
- Technical depth
- Engineering workflow
- Debug ability
- Communication skills

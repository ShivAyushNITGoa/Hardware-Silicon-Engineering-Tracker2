# L Terms — Semiconductor Glossary

## Layout

- Physical representation of an integrated circuit.
- Contains transistor geometry, metal routing, and layers.

## LVS — Layout Versus Schematic

- Verification process comparing layout with schematic.
- Ensures physical implementation matches design intent.

## Leakage Current

- Unwanted current flow when transistor is OFF.
- Major challenge in nanoscale CMOS.

## Lithography

- Process of transferring patterns onto silicon wafers.
- Uses DUV and EUV technologies.

## Logic Synthesis

- Converts RTL description into gate-level netlist.
- Major ASIC design step.

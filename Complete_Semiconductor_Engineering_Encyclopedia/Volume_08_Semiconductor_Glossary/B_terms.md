# B Terms — Semiconductor Glossary

## BGA — Ball Grid Array

**Definition:**
An IC package using an array of solder balls for electrical connection to a PCB.

**Importance:**
Provides high pin count and improved electrical performance compared with older packages.

**Applications:**
- CPUs
- GPUs
- SoCs
- Memory devices

---

## Back-End Of Line (BEOL)

**Definition:**
The fabrication stage where metal interconnects are created after transistor formation.

**Includes:**
- Metal layers
- Vias
- Dielectric layers
- Interconnect optimization

**Related:** FEOL, MOL, CMOS fabrication

---

## Back Annotation

**Definition:**
Adding extracted physical information such as delays and parasitics back into simulation models.

**Used for:**
- Gate-level simulation
- Timing verification
- Post-layout analysis

---

## Bandgap

**Definition:**
Energy difference between valence band and conduction band in a semiconductor.

**Importance:**
Determines electrical properties of semiconductor materials.

Examples:
- Silicon: ~1.12 eV
- Gallium Nitride: ~3.4 eV

---

## Biasing

**Definition:**
Applying controlled voltages or currents to set transistor operating conditions.

**Applications:**
- Analog circuits
- Amplifiers
- Current mirrors
- RF circuits

---

## Bit Cell

**Definition:**
The smallest storage element in a digital memory array.

**Examples:**
- SRAM cell
- DRAM cell
- Flash memory cell

---

## Body Effect

**Definition:**
Change in MOSFET threshold voltage due to source-to-body voltage variation.

**Importance:**
Important in CMOS design and analog circuits.

---

## Boolean Logic

**Definition:**
Mathematical system used to represent digital operations using binary values.

**Foundation of:**
- Logic gates
- Digital circuits
- Computer architecture

---

## Boundary Scan

**Definition:**
A testing method using embedded scan chains for checking PCB and IC connections.

**Standard:** IEEE 1149.1 JTAG

---

## Buffer

**Definition:**
A circuit used to strengthen or delay a signal.

**Applications:**
- Clock trees
- Signal integrity
- Fanout management

# Memory Semiconductor Dictionary

## SRAM
Static Random Access Memory.

Features:
- Fast access
- No refresh required
- Used in CPU caches

## DRAM
Dynamic Random Access Memory.

Features:
- High density
- Requires refresh
- Used as main memory

## NAND Flash
Non-volatile memory technology used in SSDs and storage devices.

## Cache Memory
High-speed memory close to processing units.

Levels:
- L1
- L2
- L3

## HBM (High Bandwidth Memory)
3D stacked DRAM technology for AI and HPC systems.

## Memory Controller
Hardware block controlling communication between processor and memory.

## Memory Hierarchy
Organization of storage:

CPU Registers
↓
Cache
↓
RAM
↓
Storage

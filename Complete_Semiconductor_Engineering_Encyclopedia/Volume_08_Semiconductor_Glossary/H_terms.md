# H-Terms — Semiconductor Glossary

## HBM — High Bandwidth Memory
- Advanced stacked memory technology.
- Uses TSV connections for high bandwidth.
- Used in GPUs, AI accelerators and HPC systems.

## HDL — Hardware Description Language
- Language used to describe digital hardware.
- Examples: Verilog, SystemVerilog, VHDL.

## HSPICE
- High accuracy SPICE simulator.
- Used for transistor-level circuit simulation and characterization.

## High-k Dielectric
- Material with high dielectric constant used in advanced MOSFET gates.
- Reduces leakage while maintaining capacitance.

## Hold Time
- Minimum time data must remain stable after clock edge.
- Important in STA and timing closure.

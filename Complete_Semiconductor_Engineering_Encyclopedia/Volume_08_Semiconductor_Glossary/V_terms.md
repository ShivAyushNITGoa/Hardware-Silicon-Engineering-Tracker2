# V Terms — Semiconductor Glossary

## VLSI — Very Large Scale Integration
Technology of integrating millions or billions of transistors on a chip.

Applications:
- CPUs
- GPUs
- SoCs
- Memory

## Verilog
Hardware Description Language used for digital design.

Used for:
- RTL design
- Simulation
- FPGA development

## Via
Vertical connection between metal layers in ICs.

Importance:
- Routing
- Interconnect design

## Voltage Scaling
Reducing supply voltage to improve power efficiency.

Used in:
- Mobile processors
- Low-power SoCs

## Verification
Process of proving hardware design correctness.

Methods:
- Simulation
- Formal verification
- Coverage analysis

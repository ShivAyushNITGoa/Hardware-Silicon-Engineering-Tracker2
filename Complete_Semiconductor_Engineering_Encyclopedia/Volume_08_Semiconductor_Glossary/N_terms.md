# N-Terms — Semiconductor Glossary

## Nanometer (nm)
Unit used to describe semiconductor feature dimensions and wavelengths.

Applications:
- Process technology nodes
- EUV lithography wavelength
- Device scaling

## NAND Flash
Non-volatile memory technology based on floating gate or charge trap transistors.

Applications:
- SSDs
- Storage devices
- Embedded memory

## Netlist
A description of circuit connectivity using components and connections.

Used in:
- Logic synthesis
- ASIC verification
- Physical design

## NMOS
N-channel MOS transistor.

Characteristics:
- Uses electrons as carriers
- Higher mobility than PMOS
- Used with PMOS in CMOS

## Noise Margin
Measure of digital circuit immunity against unwanted voltage variations.

Important for:
- Logic reliability
- CMOS design

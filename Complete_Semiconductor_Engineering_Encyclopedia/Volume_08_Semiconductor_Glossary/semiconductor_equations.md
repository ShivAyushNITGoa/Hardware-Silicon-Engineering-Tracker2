# Semiconductor Engineering Equations

## MOSFET Drain Current

Linear region:

Id = μnCox(W/L)[(Vgs-Vth)Vds - Vds²/2]

Saturation region:

Id = 1/2 μnCox(W/L)(Vgs-Vth)²

## CMOS Dynamic Power

Pdynamic = αCV²f

Where:
- α = switching activity
- C = capacitance
- V = voltage
- f = frequency

## RC Delay

Delay ≈ RC

Important in:
- Interconnect analysis
- Timing closure

## Semiconductor Conductivity

σ = q(nμn + pμp)

## Energy Band Relation

E = hν

Used in:
- Semiconductor physics
- Photonics

## Timing Slack

Slack = Required Time - Arrival Time

Used in:
- Static Timing Analysis

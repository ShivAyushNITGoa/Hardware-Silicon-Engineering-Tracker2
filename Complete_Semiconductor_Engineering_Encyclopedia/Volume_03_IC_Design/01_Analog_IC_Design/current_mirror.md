# Current Mirror

## Overview

A current mirror is an analog circuit that copies a reference current into another branch.

## Purpose

- Bias generation
- Constant current sources
- Analog IC building blocks

## Basic BJT Current Mirror

Concept:
- Reference transistor sets current
- Output transistor mirrors current

## MOS Current Mirror

Uses matched MOSFETs operating in saturation.

Important parameters:

- Matching
- Output resistance
- Compliance voltage
- Channel length modulation

## Types

- Simple current mirror
- Wilson current mirror
- Cascode current mirror

## Applications

- Op-amps
- ADC/DAC circuits
- RF ICs
- Analog processors

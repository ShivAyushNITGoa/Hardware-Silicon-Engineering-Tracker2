# Differential Pair

## Overview

A differential pair is a fundamental analog circuit that amplifies the difference between two input signals.

## Structure

- Two matched transistors
- Shared current source
- Differential outputs

## Operation

Input difference controls current steering between transistors.

## Important Parameters

- Differential gain
- Common mode rejection ratio (CMRR)
- Offset voltage
- Input range

## Applications

- Operational amplifiers
- Comparators
- ADC input stages
- RF circuits

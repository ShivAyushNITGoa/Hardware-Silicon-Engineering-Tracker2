# Verilog HDL

## Overview

Verilog is a hardware description language used to model and design digital circuits.

## Concepts

- Modules
- Ports
- Nets and variables
- Continuous assignment
- Procedural blocks
- Always blocks
- Simulation constructs

## Design Styles

- Gate level
- Dataflow
- Behavioral
- RTL

## Applications

- ASIC design
- FPGA design
- Verification

## Tools

- Icarus Verilog
- Verilator
- Vivado
- Quartus
- Synopsys tools

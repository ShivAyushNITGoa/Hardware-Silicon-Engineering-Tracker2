# Datapath Design

## Overview
Datapath is the hardware path where data is processed inside digital systems.

## Components
- ALU
- Registers
- Multiplexers
- Shifters
- Control units

## Processor Relation
Instruction → Decode → Datapath Operation → Write Back

## Design Considerations
- Performance
- Area
- Power
- Pipeline stages

## Applications
- CPUs
- GPUs
- DSP processors
- SoCs

# Sequential Logic Design

## Overview
Sequential circuits depend on current inputs and previous states.

## Elements
- Latches
- Flip-flops
- Registers
- Counters
- FSMs

## Timing Concepts
- Setup time
- Hold time
- Clock-to-Q delay
- Clock skew
- Clock jitter

## Applications
- CPU pipelines
- Memory controllers
- Digital systems
- SoCs

# Clock Tree Synthesis (CTS)

## Overview
CTS builds the clock network that distributes clock signals to sequential elements.

## Goals
- Minimize clock skew
- Reduce clock latency
- Control clock uncertainty

## Concepts
- Clock source
- Clock buffers
- Clock sinks
- Skew
- Jitter
- Latency

## Techniques
- Buffer insertion
- Clock balancing
- Clock gating

## Tools
- Synopsys ICC2
- Cadence Innovus

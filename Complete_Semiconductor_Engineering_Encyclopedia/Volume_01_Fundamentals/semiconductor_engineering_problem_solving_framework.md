# Semiconductor Engineering Problem Solving Framework

## Purpose
A practical framework for approaching semiconductor problems from physics to system level.

## Engineering Approach

1. Define the problem
2. Identify abstraction level
3. Select models and assumptions
4. Perform analysis/simulation
5. Validate results
6. Optimize performance, power, area and reliability

## Common Tradeoffs

- Performance vs Power
- Area vs Speed
- Cost vs Yield
- Density vs Reliability
- Flexibility vs Optimization

## Debug Hierarchy

System → Architecture → RTL/Circuit → Device → Process

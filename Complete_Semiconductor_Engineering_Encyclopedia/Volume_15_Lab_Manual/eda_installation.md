# EDA Installation Lab

## Purpose
Setup semiconductor design tools for practical VLSI learning.

## Open Source EDA Stack

- Yosys — synthesis
- OpenROAD — physical design
- OpenLane — RTL to GDSII flow
- Magic — layout
- KLayout — viewing and verification
- Verilator — simulation

## Installation Flow

1. Install Ubuntu environment
2. Install dependencies
3. Configure paths
4. Verify tool versions
5. Run sample designs

## Learning Experiments

- CMOS inverter synthesis
- Counter synthesis
- Timing analysis
- Basic ASIC flow

# CMOS Memory Cells

## Overview

CMOS technology enables modern semiconductor memories.

## SRAM

- 6T SRAM cell
- Fast access
- Used in CPU cache

## DRAM

- 1 transistor + capacitor cell
- Requires refresh
- High density

## Flash Memory

- Floating gate transistor
- Non-volatile storage

## Parameters

- Density
- Access time
- Leakage
- Power consumption

## Applications

- Cache
- RAM
- Storage devices

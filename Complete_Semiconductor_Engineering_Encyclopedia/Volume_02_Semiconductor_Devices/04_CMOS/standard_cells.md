# CMOS Standard Cells

## Overview
Standard cells are pre-designed CMOS building blocks used in ASIC design.

Examples:
- Inverter
- NAND
- NOR
- Flip-flops
- Multiplexers

## Cell Library Components

- Logical function
- Layout view
- Timing model
- Power model
- Physical dimensions

## ASIC Flow Usage

RTL → Synthesis → Standard Cell Mapping → Place and Route → Tapeout

## Important Parameters

- Area
- Delay
- Power
- Drive strength
- Fanout

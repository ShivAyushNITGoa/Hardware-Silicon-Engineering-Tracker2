# CMOS Flip-Flop

## Introduction

A flip-flop is an edge-triggered storage element storing one bit.

## Types

- D Flip-Flop
- JK Flip-Flop
- T Flip-Flop

## CMOS Design

Built using:
- Transmission gates
- Inverters
- Feedback paths

## Parameters

- Setup time
- Hold time
- Clock-to-Q delay
- Power consumption

## Applications

- Registers
- Counters
- Processor pipelines
- Memory interfaces

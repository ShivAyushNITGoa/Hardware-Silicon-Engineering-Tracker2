# Advanced Semiconductor Packaging

## Overview

Advanced packaging enables higher performance by integrating multiple dies and improving bandwidth.

## Technologies

### 2.5D Integration

- Multiple dies placed on an interposer
- Used in high-performance computing

### 3D IC Stacking

- Vertical die integration
- Through Silicon Vias (TSV)

### Chiplets

- Modular silicon blocks integrated into one package
- Used by modern processors

### HBM (High Bandwidth Memory)

- Stacked DRAM technology
- Very high memory bandwidth

## Applications

- AI accelerators
- GPUs
- Data center processors
- HPC systems

# Analog, RF and Memory Formula Sheet

## Analog IC

Gain:

Av = Vout / Vin

Bandwidth:

BW = f_high - f_low

## MOS Current

Id depends on:

- Mobility
- W/L ratio
- Threshold voltage
- Gate voltage

## RF Basics

Important parameters:

- Noise figure
- Gain
- Bandwidth
- SNR
- Phase noise

## Memory Design

Key parameters:

- Access time
- Write time
- Read latency
- Bit cell area
- Leakage power

## Applications

- SRAM
- DRAM
- Flash
- Cache design

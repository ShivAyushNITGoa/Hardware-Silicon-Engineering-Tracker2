# Open Source ASIC Complete Tutorial

## Goal

Learn the complete RTL to GDSII semiconductor flow using open-source tools.

## Flow

```text
RTL Design
    ↓
Simulation
    ↓
Synthesis
    ↓
Floorplanning
    ↓
Placement
    ↓
Clock Tree Synthesis
    ↓
Routing
    ↓
DRC/LVS
    ↓
GDSII
```

## Tool Chain

### RTL

- Verilog
- SystemVerilog

### Simulation

- Icarus Verilog
- Verilator

### Synthesis

- Yosys

### Physical Design

- OpenROAD
- OpenLane

### Layout

- Magic
- KLayout

## Beginner Projects

1. CMOS inverter
2. Counter
3. UART controller
4. RISC-V core

## Learning Outcome

Student should understand:

- Digital design
- Timing analysis
- Physical design
- Tapeout process

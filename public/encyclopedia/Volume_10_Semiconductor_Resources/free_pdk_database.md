# Free PDK Database

## Purpose

Process Design Kits allow semiconductor design and verification using real foundry rules.

## Open Source PDKs

## SkyWater 130nm PDK

Used for:

- Learning ASIC flow
- Open-source tapeout
- Education

## GlobalFoundries 180nm PDK

Used for:

- Analog design learning
- Mixed signal studies

## OpenROAD Compatible PDKs

Used with:

- OpenLane
- OpenROAD
- Yosys

## PDK Contents

Includes:

- Technology files
- Standard cell libraries
- Design rules
- SPICE models
- LEF/DEF files
- Timing libraries

- Ring oscillator

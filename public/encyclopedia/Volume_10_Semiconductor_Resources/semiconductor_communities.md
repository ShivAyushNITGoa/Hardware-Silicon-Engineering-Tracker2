# Semiconductor Communities Database

## Purpose

A list of communities, forums and technical networks for semiconductor learning, collaboration and research.

## Open Source Semiconductor Communities

### RISC-V Community
- Open instruction set architecture ecosystem
- CPU design discussions
- Open hardware projects

### OpenROAD Community
- Open-source ASIC physical design
- RTL to GDSII discussions

### SkyWater Open Source PDK Community
- Open silicon manufacturing projects
- Educational tapeouts

## Professional Communities

### IEEE Communities
Topics:
- VLSI
- Semiconductor devices
- Embedded systems
- Electron devices

### ACM SIGDA
Topics:
- Design automation
- EDA research
- CAD algorithms

## Learning Communities

Platforms:
- GitHub semiconductor projects

- Research groups
- Hardware design communities

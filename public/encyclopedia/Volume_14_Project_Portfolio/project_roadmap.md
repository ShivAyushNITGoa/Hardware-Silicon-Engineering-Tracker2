# Semiconductor Project Roadmap

## Beginner
- Logic circuits
- CMOS inverter
- Basic RTL modules

## Intermediate
- UART/SPI/I2C controllers
- FPGA projects
- Verification environments

## Advanced
- RISC-V processor
- ASIC flow projects
- AI accelerators

## Industry Level
- SoC design
- Tapeout projects
- Research prototypes

Each project should include:
- Specification
- Design
- Simulation
- Verification
- Documentation
- Results

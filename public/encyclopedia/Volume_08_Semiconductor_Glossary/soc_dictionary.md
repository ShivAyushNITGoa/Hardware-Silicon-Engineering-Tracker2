# SoC Dictionary

## SoC (System on Chip)
A semiconductor device integrating multiple system components on one die.

Includes:
- CPU cores
- GPU/NPU accelerators
- Memory controllers
- Peripherals
- Communication interfaces

Applications:
- Smartphones
- Automotive systems
- IoT devices
- AI edge processors

## AMBA
Advanced Microcontroller Bus Architecture by Arm.

Important protocols:
- AXI
- AHB
- APB

## IP Block
Reusable semiconductor design block used during SoC development.

Examples:
- CPU IP
- Memory IP
- Interface IP

## NoC (Network on Chip)
Communication architecture connecting blocks inside complex SoCs.

## Clock Domain Crossing (CDC)
Transfer of signals between different clock domains.

Important concepts:
- Synchronizers
- Metastability
- FIFO crossing

## Power Domain
Independent voltage-controlled region inside a SoC.

Used for:
- Power gating
- Low power operation

## Reset Architecture
Design of reset distribution and sequencing in complex chips.

## Hardware Software Co-design
Division of functionality between hardware accelerators and software execution.

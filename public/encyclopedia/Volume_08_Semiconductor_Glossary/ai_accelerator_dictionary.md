# AI Accelerator Dictionary

## Overview
AI accelerators are specialized semiconductor architectures optimized for machine learning workloads.

## NPU — Neural Processing Unit
Dedicated hardware for neural network computation.

## TPU — Tensor Processing Unit
Accelerator architecture optimized for tensor operations.

## GPU Acceleration
Uses massive parallel processing for AI workloads.

## Tensor Core
Specialized compute unit for matrix multiplication.

## TOPS — Tera Operations Per Second
Performance metric for AI hardware.

## AI Chip Architecture
Includes:
- Compute engines
- Memory hierarchy
- High bandwidth interfaces
- Control processors

## Important Design Challenges
- Power efficiency
- Memory bandwidth
- Thermal limits
- Data movement optimization

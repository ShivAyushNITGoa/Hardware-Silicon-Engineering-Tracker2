# Semiconductor Verification Dictionary

## Functional Verification
Ensures hardware behaves according to specification.

## Testbench
Environment used to test RTL designs.

## Assertion
Property used to check expected behavior.

## Coverage
Measurement of verification completeness.

## UVM
Universal Verification Methodology for reusable verification environments.

## Driver
Generates stimulus for DUT.

## Monitor
Observes DUT behavior.

## Scoreboard
Compares expected and actual results.

## Formal Verification
Mathematical proof-based verification technique.

## Regression
Automated execution of multiple verification tests.

# D Terms — Semiconductor Glossary

## DAC — Digital to Analog Converter
Converts digital codes into analog signals.

Applications:
- Audio systems
- RF transmitters
- Mixed-signal ICs

## DFT — Design For Testability
Methodology to improve IC testing.

Concepts:
- Scan chains
- Boundary scan
- Built-in self test (BIST)

## DRC — Design Rule Check
Physical verification process ensuring layout follows fabrication rules.

Checks:
- Width
- Spacing
- Enclosure
- Density

## DRAM — Dynamic Random Access Memory
Memory technology storing data using capacitors.

## DSP — Digital Signal Processing
Processing of digital signals using mathematical operations.

Applications:
- Communications
- Audio
- Image processing

## Device Physics
Study of semiconductor device operation.

Includes:
- Carrier transport
- Band theory
- MOSFET operation

## Die
Individual silicon piece containing an integrated circuit.

## Diffusion
Fabrication process where dopant atoms move through silicon using heat.

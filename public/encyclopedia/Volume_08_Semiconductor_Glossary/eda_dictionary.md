# EDA Dictionary

## Electronic Design Automation
Software ecosystem used for semiconductor design and verification.

## RTL Synthesis
Conversion of HDL code into gate-level netlist.

## Simulation
Verification of design behavior before fabrication.

## STA
Static Timing Analysis checks setup, hold and timing constraints.

## DRC
Design Rule Check verifies layout manufacturing rules.

## LVS
Layout Versus Schematic verifies physical design matches circuit intent.

## Floorplanning
Planning placement of major blocks in ASIC design.

## Placement
Positioning standard cells for timing and area optimization.

## CTS
Clock Tree Synthesis creates optimized clock distribution networks.

## Routing
Connecting cells using metal layers.

## Signoff
Final verification before tapeout.

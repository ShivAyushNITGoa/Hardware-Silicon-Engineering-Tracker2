# S-Terms Semiconductor Glossary

## SoC — System on Chip

- Complete electronic system integrated on one chip.
- Includes CPU, memory, peripherals and accelerators.

## STA — Static Timing Analysis

- Timing verification method in ASIC design.
- Checks setup, hold and clock constraints.

## SRAM — Static Random Access Memory

- Fast volatile memory technology.
- Used for processor caches.

## Synthesis

- Conversion of RTL code into gate-level netlist.
- Major ASIC front-end step.

## SystemVerilog

- Hardware description and verification language.
- Supports RTL design, assertions and UVM.

## Semiconductor Scaling

- Reduction of transistor dimensions.
- Improves density and performance.

# G Terms — Semiconductor Glossary

## GAAFET — Gate All Around FET
Advanced transistor architecture where the gate surrounds the channel.

Advantages:
- Improved gate control
- Reduced leakage
- Future CMOS scaling

## Gate Oxide
Insulating layer between MOS gate and semiconductor channel.

Importance:
- Controls threshold voltage
- Affects reliability

## GDSII
Standard file format used for IC layout data exchange.

Used in:
- ASIC tapeout
- Manufacturing handoff

## GPU — Graphics Processing Unit
Highly parallel processor used for graphics, AI and HPC workloads.

## Ground Bounce
Voltage disturbance caused by current changes in digital circuits.

## Guard Ring
Layout structure used to isolate noise and prevent latch-up.

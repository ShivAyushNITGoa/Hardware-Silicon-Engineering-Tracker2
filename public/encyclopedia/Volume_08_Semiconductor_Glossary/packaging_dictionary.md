# Semiconductor Packaging Dictionary

## Overview
Semiconductor packaging provides electrical connection, mechanical protection and thermal management.

## Wire Bonding
Connection method using thin metal wires between die and package.

Applications:
- IC packages
- Memory devices

## Flip Chip
Die is connected using solder bumps directly to substrate.

Benefits:
- Higher speed
- Better thermal performance

## BGA
Ball Grid Array package using solder balls for PCB connection.

## FCBGA
Flip Chip Ball Grid Array used in CPUs and GPUs.

## TSV
Through Silicon Via enables 3D stacking and HBM.

## Chiplet Packaging
Combines multiple dies in advanced packages.

## 2.5D Integration
Multiple dies placed on silicon interposer.

## 3D IC
Vertical stacking of semiconductor dies.

## HBM
High Bandwidth Memory using stacked DRAM dies.

# 365-Day Semiconductor Engineering Learning Plan

## Purpose
A complete one-year roadmap covering semiconductor fundamentals, IC design, fabrication, verification, tools, and industry preparation.

# Phase 1: Foundations (Day 1-60)

## Electronics Fundamentals
- Voltage, current, resistance
- Semiconductor basics
- Diodes and transistors
- MOSFET operation
- Analog and digital circuits

## Mathematics
- Calculus basics
- Differential equations
- Linear algebra
- Probability

## Programming
- C programming
- Python basics
- Linux commands
- Git workflow

# Phase 2: Semiconductor Devices (Day 61-120)

Topics:
- PN junction
- BJT
- MOS capacitor
- MOSFET models
- CMOS inverter
- Scaling challenges
- FinFET
- GAAFET

Practice:
- LTspice simulations
- Device analysis

# Phase 3: Digital Design and HDL (Day 121-180)

Topics:
- Boolean algebra
- Logic circuits
- FSM
- Timing concepts
- Verilog
- SystemVerilog
- RTL design

Projects:
- UART
- SPI controller
- RISC-V modules

# Phase 4: ASIC and FPGA Flow (Day 181-240)

Topics:
- FPGA architecture
- Synthesis
- STA
- Floorplanning
- Placement
- CTS
- Routing
- DRC/LVS

Tools:
- Vivado
- Quartus
- Yosys
- OpenROAD
- OpenLane

# Phase 5: Fabrication and Manufacturing (Day 241-290)

Topics:
- Wafer manufacturing
- Lithography
- EUV
- Etching
- Deposition
- Implantation
- CMP
- Packaging
- Yield engineering

# Phase 6: Advanced Semiconductor Engineering (Day 291-330)

Topics:
- SoC architecture
- Chiplets
- 3D IC
- HBM
- AI accelerators
- Low power design
- Advanced packaging

# Phase 7: Industry Preparation (Day 331-365)

Topics:
- Resume building
- GitHub portfolio
- Interview preparation
- Research papers
- Company-specific preparation

Companies:
- TSMC
- Intel
- NVIDIA
- AMD
- Qualcomm
- ASML
- Cadence
- Synopsys

# Final Goal
After completing this roadmap, the learner should understand the complete semiconductor lifecycle:

Silicon → Device → Circuit → RTL → ASIC → Fabrication → Packaging → Industry

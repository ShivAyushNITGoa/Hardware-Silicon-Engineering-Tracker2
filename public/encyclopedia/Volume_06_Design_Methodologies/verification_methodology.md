# Verification Methodology

## Purpose

Verification ensures that designed hardware matches specifications.

## Flow

Specification

↓

Test Plan

↓

Environment Development

↓

Simulation

↓

Coverage Analysis

↓

Signoff

## Types

### Functional Verification

Checks intended behavior.

### Formal Verification

Mathematically proves properties.

### Gate Level Verification

Checks synthesized design.

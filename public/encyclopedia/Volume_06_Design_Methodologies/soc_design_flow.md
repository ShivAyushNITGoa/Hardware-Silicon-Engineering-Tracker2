# SoC Design Flow

## Overview
System-on-Chip integrates processors, memory, peripherals, accelerators and interfaces on a single IC.

## Flow

Architecture Specification
→ IP Selection
→ Hardware/Software Partitioning
→ RTL Design
→ Verification
→ Integration
→ Synthesis
→ Physical Design
→ Signoff
→ Tapeout

## Major Blocks

- CPU cores
- GPU/NPU accelerators
- Memory controllers
- Interconnects
- Peripheral IPs
- Security blocks

## Key Concepts

- AMBA protocols (AXI, AHB, APB)
- Clock domains
- Power domains
- Reset architecture
- Firmware interaction

## Industry Applications

- Mobile processors
- Automotive chips
- AI accelerators
- Networking processors

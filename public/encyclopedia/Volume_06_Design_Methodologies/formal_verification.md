# Formal Verification

## Overview

Formal verification mathematically proves whether a design satisfies specified properties.

## Concepts

- Properties
- Assertions
- Model checking
- Equivalence checking

## Applications

- RTL verification
- Safety critical designs
- Processor verification

## Comparison

Simulation checks selected scenarios.

Formal explores possible states mathematically.

## Industry Usage

Used in:
- SoC verification
- CPU verification
- Automotive semiconductor designs

# FPGA Design Flow

## Overview

FPGA design converts hardware description into a programmable hardware implementation.

## Complete Flow

Specification

↓

Architecture Design

↓

RTL Coding (Verilog/SystemVerilog/VHDL)

↓

Simulation

↓

Synthesis

↓

Implementation

↓

Place & Route

↓

Timing Analysis

↓

Bitstream Generation

↓

FPGA Programming

## Major Concepts

- LUTs
- Flip-flops
- Block RAM
- DSP slices
- Clock management
- Constraints
- Timing closure

## Tools

- AMD Xilinx Vivado
- Intel Quartus Prime
- Lattice Radiant
- Yosys + nextpnr

# Semiconductor Formula Reference

## Basic Electronics

Ohm's Law:
V = IR

Power:
P = VI = I²R = V²/R

## Semiconductor Physics

Conductivity:
σ = q(nμn + pμp)

Carrier concentration:
n = ni² / p

## MOSFET

Drain current depends on:
- Mobility
- Gate oxide capacitance
- Channel dimensions
- Threshold voltage

## Digital Timing

Slack = Required Time - Arrival Time

Positive slack indicates timing success.

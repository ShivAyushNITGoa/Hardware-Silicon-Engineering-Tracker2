# Analog IC Engineer Career Path

## Roadmap

Electronics Fundamentals → CMOS → Analog Blocks → Mixed Signal Design

## Core Skills

- MOS transistor operation
- Analog circuit design
- Amplifiers
- Current mirrors
- ADC/DAC concepts
- Layout awareness

## Project Progression

Beginner:
- CMOS inverter
- Current mirror

Intermediate:
- Op-amp design
- Analog blocks

Advanced:
- Mixed-signal IC design
- Low-power analog circuits

## Industry Tools

- Cadence Virtuoso
- Spectre
- SPICE simulators

# Verilog Laboratory

## Objective
Learn RTL design through practical HDL experiments.

## Experiments

### Basic RTL
- Gates
- Multiplexers
- Adders
- Flip-flops

### Intermediate RTL
- Counters
- FSM controllers
- UART
- SPI
- FIFO

### Advanced RTL
- RISC-V blocks
- SoC modules
- Hardware accelerators

## Workflow

RTL → Simulation → Synthesis → FPGA/ASIC implementation

## Tools

- Icarus Verilog
- Verilator
- GTKWave
- Vivado
- Quartus

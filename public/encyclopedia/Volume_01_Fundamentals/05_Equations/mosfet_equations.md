# MOSFET Equations

## Regions of Operation

### Cutoff Region

VGS < VTH

No channel formation.

### Linear Region

The MOSFET behaves as a voltage controlled resistor.

Id = μCox(W/L)[(VGS-VTH)VDS - VDS²/2]

### Saturation Region

Id = 1/2 μCox(W/L)(VGS-VTH)²

## Important Parameters

- Threshold voltage
- Channel length
- Channel width
- Mobility
- Oxide capacitance

## Applications

Used in:
- CMOS logic
- CPUs
- GPUs
- Memory
- Analog ICs

# Semiconductor Equations

## Overview

Core mathematical relationships used in semiconductor physics, device analysis and IC design.

## Charge Density

Electron concentration:

`n`

Hole concentration:

`p`

Charge density:

ρ = q(p - n + N_D - N_A)

## Intrinsic Semiconductor

For intrinsic material:

n = p = n_i

Mass action law:

np = n_i²

## Conductivity

σ = q(nμn + pμp)

where:
- μn = electron mobility
- μp = hole mobility

## Current Density

Drift current:

J = σE

Diffusion current:

J = qD(dn/dx)

## Applications

These equations are used in:
- Diode analysis
- MOSFET modeling
- TCAD simulation
- Semiconductor process design

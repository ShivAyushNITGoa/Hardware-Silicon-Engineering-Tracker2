# Siemens EDA Tools

## Overview
Siemens EDA (formerly Mentor Graphics) provides tools for IC design, verification and semiconductor manufacturing analysis.

## Major Tools

### Calibre
Industry standard physical verification platform.

Used for:
- DRC
- LVS
- Reliability checks
- Manufacturing verification

### Tanner EDA
Used for:
- Analog IC design
- Schematic capture
- Layout
- Simulation

### QuestaSim
Used for:
- HDL simulation
- Functional verification
- SystemVerilog verification

### Eldo
Analog circuit simulator used for:
- Analog design verification
- Device modelling

## Applications
- ASIC signoff
- Analog IC design
- Semiconductor manufacturing
- Verification

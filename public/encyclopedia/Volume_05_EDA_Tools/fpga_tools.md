# FPGA Design Tools

## Overview
FPGA tools convert HDL designs into programmable hardware implementations.

## Xilinx AMD Vivado

Used for:
- RTL synthesis
- Simulation
- Implementation
- Bitstream generation

Devices:
- Artix
- Kintex
- Virtex
- Zynq

## Intel Quartus Prime

Used for:
- FPGA synthesis
- Place and route
- Timing analysis

Devices:
- Cyclone
- Arria
- Stratix

## Open Source Tools

### Yosys
RTL synthesis

### nextpnr
FPGA place and route

### Verilator
Fast simulation

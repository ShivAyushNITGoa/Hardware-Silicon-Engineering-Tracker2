# Semiconductor Verification Tools

## Purpose

Verification ensures hardware correctness before fabrication.

## Simulation Tools

- Synopsys VCS
- Cadence Xcelium
- Siemens QuestaSim

Used for:
- RTL simulation
- SystemVerilog verification
- UVM testing

## Debug Tools

- Synopsys Verdi
- Cadence SimVision

## Formal Verification

Tools:
- Synopsys VC Formal
- Cadence JasperGold

Applications:
- SoC verification
- Safety critical designs
- Processor verification

## Verification Flow

RTL → Simulation → Coverage → Formal Checks → Signoff

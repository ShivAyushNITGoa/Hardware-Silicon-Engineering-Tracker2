# Wafer Testing

## Overview

Wafer testing is performed before packaging to identify defective dies and improve manufacturing yield.

## Test Flow

```
Fabricated Wafer
        ↓
Probe Testing
        ↓
Electrical Measurement
        ↓
Die Classification
        ↓
Packaging Decision
```

## Wafer Probe

Components:
- Probe card
- Tester system
- Wafer prober

Checks:
- Voltage levels
- Leakage current
- Frequency performance
- Memory operation

## Test Types

### Parametric Testing

Measures:
- Threshold voltage
- Resistance
- Capacitance
- Leakage

### Functional Testing

Checks:
- Logic operation
- Memory access
- Interface operation

## Importance

- Improves yield
- Reduces packaging cost
- Detects manufacturing defects

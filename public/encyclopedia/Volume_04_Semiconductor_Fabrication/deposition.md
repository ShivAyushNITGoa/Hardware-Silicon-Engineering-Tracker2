# Semiconductor Deposition

## Overview

Deposition adds thin material layers during chip fabrication.

## Major Techniques

## CVD

Chemical Vapor Deposition creates films using chemical reactions.

Applications:

- Silicon nitride
- Oxides
- Dielectrics

## PVD

Physical Vapor Deposition uses physical processes to deposit metals.

## ALD

Atomic Layer Deposition provides atomic-level thickness control.

Applications:

- High-k dielectric
- Advanced transistor structures

## Importance

Critical for:

- Gate stacks
- Interconnects
- Memory devices

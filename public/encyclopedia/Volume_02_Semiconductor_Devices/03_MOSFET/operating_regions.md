# MOSFET Operating Regions

## Overview
MOSFET operation is divided into three main regions.

## Cutoff Region
- VGS < VTH
- No inversion channel
- Device OFF

## Linear Region
- Channel exists from source to drain
- MOSFET behaves like a voltage-controlled resistor

Equation:

ID = μCox(W/L)[(VGS-VTH)VDS - VDS²/2]

## Saturation Region
- Pinch-off occurs near drain
- Used for amplification and current sources

Equation:

ID = 1/2 μCox(W/L)(VGS-VTH)²

## Applications
- Digital switching
- Analog amplifiers
- Current sources

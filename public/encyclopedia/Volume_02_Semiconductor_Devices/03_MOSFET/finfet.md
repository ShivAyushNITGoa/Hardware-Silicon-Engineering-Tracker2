# FinFET (Fin Field Effect Transistor)

## Overview

FinFET is a 3D transistor architecture developed to overcome planar MOSFET scaling limitations.

## Why FinFET Was Introduced

Problems in planar MOSFET:

- Short channel effects
- Leakage current
- Poor gate control

## Structure

FinFET uses a vertical silicon fin as the channel.

```
        Gate
     __________
    |          |
    |   FIN    |
    |__________|

 Source ---- Drain
```

## Advantages

- Better electrostatic control
- Lower leakage
- Higher performance
- Improved scaling

## Parameters

- Fin height
- Fin width
- Number of fins
- Gate pitch

## Industry Usage

Used by:

- Intel
- TSMC
- Samsung

Applications:

- CPUs
- GPUs
- Mobile SoCs
- AI accelerators

## Challenges

- Complex fabrication
- Increased process cost
- Lithography challenges

## Evolution

Planar MOSFET → FinFET → GAAFET

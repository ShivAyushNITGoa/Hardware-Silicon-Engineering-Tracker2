# NMOS Transistor

## Overview

NMOS uses electrons as the primary carriers and forms an n-type channel between source and drain.

## Structure

- P-type substrate
- N+ source
- N+ drain
- Gate oxide
- Gate terminal

## Operation

When gate voltage exceeds threshold voltage, an inversion channel forms.

## Advantages

- Higher mobility
- Faster switching compared with PMOS

## Applications

- CMOS logic
- Digital circuits
- Memory cells

## Important Parameters

- Threshold voltage
- Mobility
- Channel length
- Drain current

# NAND and NOR CMOS Design

## NAND Gate

A CMOS NAND gate uses:
- PMOS transistors in parallel
- NMOS transistors in series

## Operation

| Input | Output |
|---|---|
| Any input 0 | 1 |
| All inputs 1 | 0 |

## Design Concepts
- Pull-up network
- Pull-down network
- Transistor sizing
- Delay optimization

---

## NOR Gate

A CMOS NOR gate uses:
- PMOS transistors in series
- NMOS transistors in parallel

## Operation

| Input | Output |
|---|---|
| All inputs 0 | 1 |
| Any input 1 | 0 |

## Applications
- Standard cells
- Logic synthesis
- Digital IC design

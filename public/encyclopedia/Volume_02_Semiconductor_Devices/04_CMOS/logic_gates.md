# CMOS Logic Gates

## Introduction

CMOS logic gates are constructed using complementary NMOS and PMOS transistor networks.

## NOT Gate (CMOS Inverter)

Structure:
- PMOS pull-up
- NMOS pull-down

Operation:

Input 0 → Output 1

Input 1 → Output 0

## NAND Gate

- Series NMOS network
- Parallel PMOS network

Applications:
- Universal logic building block
- Standard cell libraries

## NOR Gate

- Parallel NMOS network
- Series PMOS network

## Other Gates

Covered:
- AND
- OR
- XOR
- XNOR
- Multiplexers

## Design Parameters

- Transistor sizing
- Delay
- Power
- Area
- Noise margin

## Industry Connection

CMOS logic gates are the foundation of ASIC standard cells.

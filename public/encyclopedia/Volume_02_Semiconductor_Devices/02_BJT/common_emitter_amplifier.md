# Common Emitter Amplifier

## Overview
The common emitter amplifier is one of the most important BJT amplifier configurations used for voltage amplification.

## Structure
- Input: Base terminal
- Output: Collector terminal
- Emitter: Common reference

## Working Principle
A small change in base current produces a larger change in collector current, creating voltage amplification across the collector resistor.

## Characteristics
- High voltage gain
- Medium input impedance
- High output impedance
- 180 degree phase inversion

## Gain
Voltage gain depends on:
- Transconductance
- Collector resistance
- Emitter resistance

## Applications
- Audio amplifiers
- Analog IC building blocks
- Signal conditioning

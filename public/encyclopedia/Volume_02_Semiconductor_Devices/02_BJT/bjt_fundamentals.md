# Bipolar Junction Transistor (BJT) Fundamentals

## 1. Overview

A Bipolar Junction Transistor is a three-terminal semiconductor device that uses both electrons and holes for operation.

Terminals:
- Emitter
- Base
- Collector

Types:
- NPN
- PNP

## 2. Prerequisites

- Semiconductor physics
- PN junction
- Carrier transport
- Doping

## 3. Structure

NPN:

Emitter (N+) → Base (P) → Collector (N)

PNP:

Emitter (P+) → Base (N) → Collector (P)

## 4. Operating Principle

A small base current controls a larger collector current.

Current relation:

Ic = βIb

where β is current gain.

## 5. Operating Regions

### Cutoff

Transistor OFF.

### Active

Used for amplification.

### Saturation

Transistor fully ON.

## 6. Applications

- Amplifiers
- Switching circuits
- Analog ICs
- Power electronics

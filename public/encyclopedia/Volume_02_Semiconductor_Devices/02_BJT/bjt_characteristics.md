# BJT Characteristics

## Overview

Bipolar Junction Transistor characteristics describe the relationship between voltage, current, gain, and operating regions.

## Output Characteristics

Shows relationship between:

- Collector current (IC)
- Collector-emitter voltage (VCE)
- Base current (IB)

Regions:

### Cutoff Region
- Transistor OFF
- IC approximately zero

### Active Region
- Amplification region
- IC controlled by IB

### Saturation Region
- Transistor fully ON
- Used in switching

## Input Characteristics

Relationship between:

- Base current
- Base-emitter voltage

Similar to forward biased diode behavior.

## Transfer Characteristics

Relationship between:

- Input current IB
- Output current IC

## Important Parameters

- Current gain (β)
- Early voltage
- Input resistance
- Output resistance
- Transconductance

## Applications

- Amplifiers
- Analog IC design
- Switching circuits
- Current mirrors

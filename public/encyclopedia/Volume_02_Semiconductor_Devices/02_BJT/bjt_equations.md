# BJT Equations

## Current Relations

Emitter current:

IE = IC + IB

Collector current:

IC = βIB

## Current Gain

β = IC / IB

## Transconductance

gm = IC / VT

## Important Parameters

- Current gain
- Saturation voltage
- Thermal voltage
- Early voltage

## Usage

These equations are used in:

- Amplifier design
- Analog IC analysis
- Device modeling

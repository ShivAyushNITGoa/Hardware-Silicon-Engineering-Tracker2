# BJT Current Mirror

## Overview
A BJT current mirror copies a reference current and generates a controlled output current.

## Principle
Uses matched transistors operating in active region.

## Basic Operation
- Reference transistor sets current
- Output transistor mirrors current

## Applications
- Bias circuits
- Analog IC design
- Differential amplifiers
- Operational amplifiers

## Important Parameters
- Current matching
- Output resistance
- Compliance voltage
- Temperature stability

## Advanced Topics
- Wilson current mirror
- Cascode current mirror

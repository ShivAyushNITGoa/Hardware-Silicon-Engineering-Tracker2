# DRC and LVS Physical Verification

## Design Rule Check (DRC)

Checks whether layout follows fabrication rules.

Checks:
- Width rules
- Spacing rules
- Enclosure rules
- Density rules

## Layout Versus Schematic (LVS)

Checks whether physical layout matches schematic/netlist.

## Importance

Required before tapeout.

## Tools

- Calibre
- Pegasus
- Assura

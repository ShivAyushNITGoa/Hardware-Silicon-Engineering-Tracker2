# OpenROAD Flow

## Purpose

OpenROAD provides open-source tools for automated physical design.

## Capabilities

- Floorplanning
- Placement
- Clock tree synthesis
- Routing
- Timing optimization

## Applications

- Education
- Research
- Open-source tapeouts
- ASIC experimentation

## Related Tools

- OpenLane
- OpenSTA
- TritonRoute
- FastRoute

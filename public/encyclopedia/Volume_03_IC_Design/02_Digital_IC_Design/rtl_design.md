# RTL Design

## Overview
Register Transfer Level (RTL) describes digital hardware using:

- Registers
- Data movement
- Combinational logic
- Clocked behavior

RTL is the bridge between system architecture and physical silicon.

## Design Flow

Specification → Architecture → RTL → Simulation → Synthesis → Netlist → Physical Design

## Core Concepts

- Clock domains
- Reset design
- Pipelines
- State machines
- Datapaths
- Control logic

## Industry Usage

RTL is used for:

- CPUs
- GPUs
- SoCs
- ASICs
- FPGA designs

## Languages

- Verilog
- SystemVerilog
- VHDL

# Combinational Logic Design

## Overview
Combinational circuits produce outputs based only on present inputs.

## Building Blocks
- Logic gates
- Adders
- Subtractors
- Multiplexers
- Encoders
- Decoders

## Design Flow
Specification → Boolean expression → Optimization → Gate implementation

## Important Concepts
- Propagation delay
- Fan-in
- Fan-out
- Logic optimization
- Power and area tradeoff

## Applications
- ALU
- Data paths
- Control logic
- Processors

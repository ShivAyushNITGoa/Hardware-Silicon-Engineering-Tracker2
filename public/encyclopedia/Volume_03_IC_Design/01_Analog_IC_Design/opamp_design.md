# Operational Amplifier Design

## Overview

Operational amplifiers are high-gain analog blocks used in signal processing.

## Internal Blocks

- Differential input stage
- Gain stage
- Output stage
- Frequency compensation

## Key Parameters

- Open loop gain
- Bandwidth
- Slew rate
- Input offset voltage
- CMRR
- PSRR

## Applications

- Filters
- ADC/DAC
- Sensor interfaces
- Control circuits
